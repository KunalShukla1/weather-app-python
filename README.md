# ☀️ Simple Weather App (Python + API)

This is a beginner-friendly Python project that shows **today's weather** for any city using a public weather API. It fetches real-time data like temperature, condition, humidity, and wind speed, and displays it in a clean format.

## 📌 Features

- Get current weather for any city
- Displays:
  - Temperature
  - Weather Condition (e.g., Clear, Rain, Snow)
  - Humidity
  - Wind Speed
- Simple and clean code using Python
- Error handling for wrong or empty city names

## 🔧 Tech Stack

- **Python 3**
- **Requests** library (for API calls)
- **OpenWeatherMap API** (or any similar weather API)
- Optional: `Tkinter` for GUI version
